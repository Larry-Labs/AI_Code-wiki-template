## Web 后端

### 架构概览

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   客户端     │────▶│   API 层    │────▶│   服务层    │
│  (Web/App)  │     │  (路由/鉴权) │     │  (业务逻辑) │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                                        ┌──────▼──────┐
                                        │   数据层    │
                                        │  (DB/缓存)  │
                                        └─────────────┘
```

### 分层说明

| 层 | 职责 | 可调用 | 不可调用 |
|----|------|--------|----------|
| API 层 | 路由、参数校验、鉴权 | 服务层 | 数据层直接访问 |
| 服务层 | 业务逻辑、事务编排 | 数据层 | API 层 |
| 数据层 | 数据访问、缓存 | 外部存储 | 服务层、API 层 |

### 模块清单

| 模块 | 目录 | 职责 |
|------|------|------|
| 认证 | `src/auth/` | 登录、注册、JWT 管理 |
| 用户 | `src/users/` | 用户 CRUD、权限管理 |
| 支付 | `src/payments/` | Stripe 集成、订单管理 |
| 通知 | `src/notifications/` | 邮件、站内信发送 |

### 外部依赖

```
本项目 ──▶ Stripe (支付)
       ──▶ Resend (邮件)
       ──▶ S3 (文件存储)
       ──▶ PostgreSQL (数据库)
       ──▶ Redis (缓存)
```

### 部署架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Nginx     │────▶│  App (x3)   │────▶│ PostgreSQL  │
│  (负载均衡)  │     │  (容器)     │     │  (主从)     │
└─────────────┘     └──────┬──────┘     └─────────────┘
                           │
                    ┌──────▼──────┐
                    │   Redis     │
                    │  (缓存/队列) │
                    └─────────────┘
```

## 嵌入式

### 架构概览

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Hardware   │────▶│    HAL      │────▶│   Drivers   │
│  (MCU/外设) │     │ (硬件抽象层) │     │ (SHT31/SX1276)│
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                                        ┌──────▼──────┐
                                        │   Tasks     │
                                        │ (FreeRTOS)  │
                                        └──────┬──────┘
                                               │
                                        ┌──────▼──────┐
                                        │   App Logic │
                                        │ (采集/发送)  │
                                        └─────────────┘
```

### 分层说明

| 层 | 职责 | 可调用 | 不可调用 |
|----|------|--------|----------|
| HAL 层 | 硬件抽象、寄存器操作 | 硬件外设 | 应用层 |
| Driver 层 | 外设驱动（传感器/通信） | HAL | Task |
| Task 层 | FreeRTOS 任务调度 | Driver | HAL |
| App 层 | 业务逻辑编排 | Task | Driver/HAL |

### 模块清单

| 模块 | 目录 | 职责 |
|------|------|------|
| 传感器驱动 | `drivers/sht31.c` | SHT31 温湿度采集 |
| LoRa 驱动 | `drivers/sx1276.c` | SX1276 LoRa 通信 |
| 环形缓冲区 | `src/buffer/ring.c` | 采集数据暂存 |
| 采集任务 | `src/tasks/sensor_task.c` | 定时传感器采集 |
| 发送任务 | `src/tasks/lora_task.c` | LoRa 数据上报 |

#### 架构概览（BSW 分层）

```
┌─────────────────────────────────────────────────────────────┐
│                    Application Layer                        │
│  ┌───────────┐  ┌───────────┐  ┌───────────┐               │

│  │ (车灯控制) │  │ (诊断管理) │  │ (状态采集) │               │
│  └─────┬─────┘  └─────┬─────┘  └─────┬─────┘               │
│        └──────────────┼──────────────┘                      │
│                       ▼                                     │
│              ┌────────────────┐                             │
│              │       RTE      │  (Runtime Environment)      │
│              │  Sender-Receiver│  (自动生成，勿手改)          │
│              └───────┬────────┘                             │
├──────────────────────┼──────────────────────────────────────┤
│                 Services Layer                              │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐            │
│  │ COM  │ │ DCM  │ │ DEM  │ │ NVM  │ │  NM  │            │
│  │通信管理│ │诊断通信│ │诊断事件│ │非易失 │ │网络管理│            │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘            │
├─────────────────────────────────────────────────────────────┤
│              ECU Abstraction Layer                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐                   │
│  │ CanIf    │ │ LinIf    │ │ EepIf    │                   │
│  │CAN 接口层 │ │LIN 接口层 │ │EEPROM 接口│                   │
│  └──────────┘ └──────────┘ └──────────┘                   │
├─────────────────────────────────────────────────────────────┤
│                 MCAL Layer                                  │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐            │
│  │ CAN  │ │ SPI  │ │ ADC  │ │ DIO  │ │ PWM  │            │
│  │驱动   │ │驱动   │ │驱动   │ │驱动   │ │驱动   │            │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘            │
└─────────────────────────────────────────────────────────────┘
```

#### 分层说明

| 层 | 职责 | 可调用 | 不可调用 |
|----|------|--------|----------|
| Application SWC | 业务逻辑（手写） | RTE API | BSW 直接 API、MCAL |
| RTE | SWC 间通信（自动生成） | BSW API | MCAL |
| Services | 系统服务（COM/DCM/DEM/NVM） | ECU Abstraction | MCAL |
| ECU Abstraction | 硬件无关接口 | MCAL | Application |
| MCAL | 硬件驱动（自动生成配置） | 寄存器 | 上层所有模块 |

#### 模块清单

| 模块 | 目录 | 职责 |
|------|------|------|
| DiagManager SWC | `src/swc/DiagManager/` | UDS 诊断请求处理 |
| LightControl SWC | `src/swc/LightControl/` | 车灯控制逻辑 |
| SensorAcq SWC | `src/swc/SensorAcq/` | 传感器数据采集 |
| COM 配置 | `generated/Com/` | CAN 信号收发配置 |
| DCM 配置 | `generated/Dcm/` | 诊断服务路由配置 |
| DEM 配置 | `generated/Dem/` | 诊断事件和 DTC 配置 |
