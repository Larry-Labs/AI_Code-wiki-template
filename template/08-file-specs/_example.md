# 文件规格示例

> 每个核心文件一个规格文件。只写关键文件，不需要覆盖所有文件。
> 文件路径对应源码路径，去掉文件扩展名。
> 参考 guides/08-file-specs-guide.md 查看各项目类型的文件规格示例。

---

## 文件规格模板

```markdown
# {文件路径}

## 职责
一句话说明这个文件做什么

## 导出
函数/类/接口的完整签名（类型必须精确）

## 依赖
- `模块名` — 用途

## 关键实现细节
- AI 会踩坑的点
- 非直觉的行为
- 协议/硬件约束

## 被调用者
- `调用方文件路径`

## 调用
- `被调用文件路径`
```
